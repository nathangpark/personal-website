FPGA Chess

Advanced Digital Design Course Project

Home / Projects / FPGA Chess

Overview

Description

Real-time hardware-based chess game implemented on the Nexys A7-100T FPGA using Verilog and DDR-backed VGA graphics.

  • Built a fully functional chess engine in Verilog with legal move validation, special moves (castling, en passant), and real-time game state transitions using finite state machines.
  • Utilized Vivado for synthesis and implementation, and employed Icarus Verilog + GTKWave for waveform-based design verification and debugging.

Features

  • Full mouse incorporation through integrated PS/2 interface
  • Move sound effects with external speaker
  • Full chess logic with piece types, check, checkmates, and illegal moves
  • Fully visual display through onboard VGA interface

Design Concepts

  • Modular Verilog design with FSM-driven chess logic and display control
  • Sequential reuse of logic modules to minimize LUT usage and resource load
  • Register-based synchronization to eliminate combinational feedback paths
  • Simulated board states for legal move and checkmate validation
  • Custom VGA controller for layered, clock-synchronized rendering
