Overview

Description

Developed a poker game using TypeScriptX, Vite, and React, with CSS for styling, in Visual Studio Code IDE. Hosted entirely on GitHub pages.

  • Designed intuitive functions and classes to streamline development of game mechanics, such as card storage, winner calculation, and chip distribution, enabling flexible expansion and easier maintenanc
  • Constructed and implemented 10+ modular React components representing cards, suits, and card groups for front end design.
  • Integrated custom algorithms to simulate intelligent opponents, ranging from 1 to 7 opponents at once.
  • Ensured clean, maintainable code with thorough documentation and comments throughout the project

Current Features

  • Random cards and card group management
  • Betting/Raising, Calling/Checking, Folding
  • Variable bets
  • Complex algorithms for opponent's choices
  • Chips management

Design Concepts

  • Custom TypeScript classes for players, cards, hands, and card groups
  • Constructors for controlled object initialization
  • Getters and setters for encapsulated state access
  • Object-oriented design to separate logic from UI
  • Single Hook class managing game state and UI updates
  • Bot decision algorithm uses hand strength, pot odds, and randomization to determine fold, call, or raise actions.
  • Incorporates probabilistic weighting for bluffing and bet sizing based on game phase and chip count.
